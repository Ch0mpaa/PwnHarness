# PwnHarness

Local-first external penetration-testing application architecture designed around small local models, deterministic tools, structured engagement state, evidence-backed review, and human-controlled execution.

> Status: early architecture bootstrap.

## Design constraint

PwnHarness targets a 4B local model by moving engagement memory, methodology, evidence, and tool execution into the application rather than relying on a long model conversation.

## Imported references

Reusable Screwhead components are copied into `legacy/screwhead/` unchanged for analysis and extraction. The source repository remains `Ch0mpaa/Lilc` and is not modified by this project.
